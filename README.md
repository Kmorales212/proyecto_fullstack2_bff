\# Proyecto Colegio - BFF (Backend for Frontend)



Orquestador de servicios encargado de agregar las respuestas de los microservicios y entregarlas al frontend.



\## Tecnologías

\- Spring Boot

\- Java



\## Propósito

Actúa como capa intermedia (Gateway) para optimizar las peticiones del frontend y desacoplar la lógica de los servicios internos.
